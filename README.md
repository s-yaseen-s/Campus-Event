# Campus Event Guide

A static, multi-page campus events website prototype for discovering events and browsing event information. The pages share a common navigation and stylesheet and are designed to work directly in a modern browser.

## Pages

- `index.html` — landing page with featured and upcoming events
- `events.html` — event listings
- `event-details.html` — example event detail page
- `schedule.html` — event schedule
- `registration.html` — registration form interface
- `contact.html` — contact page
- `style.css` — shared layout, responsive styling, and visual theme

## Built with

- HTML5
- CSS3

## Run locally

No build step or package installation is required. Clone the repository and open `index.html` in a browser. To serve the files locally instead, run this from the repository directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Note

This is a front-end prototype. The pages and form interfaces demonstrate the user experience; no server-side event database, registration processing, or contact form service is configured in this repository.
